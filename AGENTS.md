# AGENTS

## Objetivo actual

Construir un backend pequeno para gestionar casos de incidentes y ART, empezando por el flujo minimo que une admision, atencion y trazabilidad, con un core comun y backoffice ART como primera vista.

## Reglas de trabajo

- avanzar por fases pequenas;
- no implementar funciones clinicas no pedidas;
- no construir integraciones complejas al inicio;
- no agregar abstracciones sin uso real;
- priorizar legibilidad y menor diff posible;
- usar datos sinteticos para ejemplos y pruebas.

## Prioridad vigente

La prioridad actual es la Fase 0 definida en [docs/implementation-plan.md](/D:/Proyectos/Salud/docs/implementation-plan.md).

## Forma de colaborar

- primero acordar el corte funcional;
- luego implementar una fase;
- ejecutar verificaciones;
- resumir cambios y pendientes;
- no saltar a la fase siguiente sin decidirlo juntos.
